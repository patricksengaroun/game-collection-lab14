# Design artifacts

1. `call_traces.md`: a hand-drawn call trace for `contains(&[7, 12, 3], 3)` and for
   `all_distinct(&[4, 9, 4])`. One box per call, showing the list it received and what it returns.
2. Revised flowcharts for each changed function: `exits`, `is_exit`, `print_warnings`,
   `place_hazards`, `bat_destination`, `wake_wumpus`, and `play` (as images or PDFs).
3. An updated structure chart for the whole project, including all modules.
